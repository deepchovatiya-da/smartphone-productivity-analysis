# Smartphone Usage & Productivity Analysis

## Project Overview
EDA and machine learning analysis on a dataset of 50,000 
smartphone users to understand how daily habits affect 
work productivity.

## Key Finding
Dataset was identified as synthetically generated through 
statistical investigation — near-zero correlations across 
all features confirmed variables were created independently. 
This became the central analytical insight of the project.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Analysis Performed
- Univariate, bivariate and multivariate EDA
- Correlation and covariance analysis
- Simple and Multiple Linear Regression
- Logistic Regression for classification
- Overfitting and underfitting analysis
- Live productivity prediction tool

## Results
- Best model R² = 0.758 after optimized split methodology
- Dataset confirmed synthetic — all correlations below 0.01
- Key lesson: data quality validation is as important 
  as modeling itself
